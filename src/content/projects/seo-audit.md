## Brief

A local plumbing and HVAC company ranked on page 3–5 for their core service keywords in a mid-sized city. They had no dedicated SEO work done previously.

## Audit scope

Using **Screaming Frog** for crawl data and **Semrush** for keyword and backlink analysis, I audited:

- **Technical** — crawl errors, redirect chains, canonical mismatches, sitemap coverage, robots.txt, page speed (Core Web Vitals via PageSpeed Insights API).
- **On-page** — title tag duplication, missing H1s, thin content pages, image alt coverage.
- **Off-page** — referring domain count, anchor text distribution, toxic link flags.

## Key findings

| Priority | Issue | Impact |
|----------|-------|--------|
| P1 | 12 pages returning soft 404 | High |
| P1 | LCP > 4s on mobile homepage | High |
| P2 | 8 duplicate title tags | Medium |
| P3 | 0 structured data (LocalBusiness) | Medium |

## Deliverables

1. Prioritised issue list with fix instructions for each item.
2. Keyword gap matrix — 120 local-intent queries grouped by service page.
3. Content brief for 4 new service landing pages.

## Projected impact

Based on similar audits, fixing P1 issues alone is expected to lift organic impressions by 35–50% within 90 days.
